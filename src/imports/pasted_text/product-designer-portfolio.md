Product Designer Portfolio Website
Goal
Create a polished, modern single-page portfolio website for a Product Designer / UX/UI Designer.
The primary audience is recruiters, design leads, and product leaders at technology companies.
The portfolio should communicate:
Strong product thinking
Excellent UI and visual design skills
Ability to solve complex UX problems
Professionalism and seniority
A clear, confident design point of view
The site should feel intentionally designed rather than like a generic portfolio template.
Visual Direction
Style
Minimal
High contrast
Clean and sophisticated
Generous whitespace
Strong typography
Subtle visual hierarchy
Modern tech/product aesthetic
References
Take visual inspiration from:
Linear.app
stripe.com/jobs
Do not directly copy either site. Use them as references for typography, spacing, restraint, layout quality, and attention to detail.
Colors
Use a restrained palette:
Off-white or very light neutral background
Near-black primary text
Muted gray secondary text
One subtle accent color
Avoid gradients unless they are extremely subtle.
Typography
Use a modern sans-serif typeface.
Typography should carry much of the visual identity:
Large, confident hero headline
Strong hierarchy
Compact labels and metadata
Highly readable body text
Use generous spacing rather than decorative elements.

Interaction Design
Use subtle, polished interactions throughout:
Smooth scrolling between sections
Navigation changes subtly on scroll
Gentle hover states
Project images slightly scale or shift on hover
Links have a refined animated state
Sections may subtly fade/translate into view while scrolling
Animations should feel premium and restrained.
Avoid excessive motion.
Responsive Design
Design the site responsively for:
Desktop
Primary experience. Use generous margins and large typography.
Tablet
Maintain hierarchy while reducing whitespace appropriately.
Mobile
Use a clean single-column layout.
Project cards should stack naturally and remain visually strong.
Navigation should simplify appropriately on smaller screens.
Figma / Component Structure
Build the interface using reusable components and Auto Layout.
Create reusable components for:
Navigation
Buttons / text links
Project cards
Tags
Social links
Footer
Use consistent:
Spacing tokens
Typography styles
Color variables
Border radius
Layout grids
Prefer Auto Layout throughout the design.
Keep the component architecture simple, logical, and easy to modify.
Important Design Principles
Prioritize, in this order:
My work
Strong typography
Clear information hierarchy
Whitespace and composition
Subtle interaction and polish
The portfolio should feel like it was designed by an experienced product designer.
Avoid:
Generic portfolio templates
Excessive cards
Large rounded containers everywhere
Excessive gradients
Decorative blobs
Stock illustrations
Unnecessary icons
Overly playful animations
Filling every area with content
When in doubt, use less UI, more whitespace, stronger typography, and larger project imagery.
